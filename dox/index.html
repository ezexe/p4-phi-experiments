p4-phi · dox

Documents you can work with your hands

p4-phi is a Claude Code plugin that links Claude desktop sessions into a tree. Each page here is one self-contained HTML file. Open one, change what it shows, and copy the commands it prints.

Documents

  • The session tree

    Start top sessions, children and grandchildren on a live tree. Detach, reparent, branch a queue by file set, and mark a session done. Each move prints the real call or command that performs it.

    session-tree.html
The plugin's code is in ezexe/p4, under lbiza/plugins/p4-phi. These pages are in ezexe/p4-phi, under dox/.
